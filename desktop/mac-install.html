Mac install

SYE is not damaged

macOS Gatekeeper · SYE Desktop v1.0.0

Important: If macOS says “SYE is damaged and can’t be opened”, the download is fine. Apple blocks apps from the web that are not yet signed and notarized. Do not delete SYE — follow the steps below.

Install SYE

  1. Download SYE-mac-1.0.0.zip and double-click it in Finder to unzip.
  2. Drag SYE.app to your Applications folder.
  3. First launch: Right-click (or Control-click) SYE.app → Open → click Open in the dialog. Do not double-click the first time.

Still blocked?

System Settings: Open System Settings → Privacy & Security. After trying to open SYE once, look for “Open Anyway” next to a message about SYE being blocked.

Terminal (removes Apple’s quarantine flag — safe for apps you downloaded from this site):

xattr -cr /Applications/SYE.app

If SYE is still in Downloads, use:

xattr -cr ~/Downloads/SYE.app

Then open SYE normally.

What the messages mean

  • “Damaged and can’t be opened” — quarantine on an unsigned app, not a corrupt file.
  • “Developer cannot be verified” — same; use Right-click → Open or Open Anyway.
  • “Move to Trash” — Gatekeeper; don’t trash it — use the steps above.
