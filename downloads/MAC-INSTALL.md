# Installing SYE on Mac

SYE Desktop v1.0.0 is **signed and notarized** by Apple.

## Install (recommended — DMG)

1. **Download** [SYE-mac-1.0.0.dmg](/downloads/SYE-mac-1.0.0.dmg) (~107 MB).
2. **Open the DMG** in Finder.
3. **Drag `SYE - Save Your Eyes`** to your **Applications** folder.
4. **Open SYE** from Applications.

## Alternate — ZIP

If the DMG link does not work on your connection, use [SYE-mac-1.0.0.zip](/downloads/SYE-mac-1.0.0.zip) (~98 MB): unzip → drag to Applications → open.

No Privacy & Security workaround needed.
