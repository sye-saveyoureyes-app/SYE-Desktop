# Installing SYE on Mac

SYE Desktop v1.0.0 is **signed and notarized** by Apple. Install it like any normal Mac app.

## Install

1. **Download** [SYE-mac-1.0.0.zip](/downloads/SYE-mac-1.0.0.zip) (~97 MB).
2. **Double-click the ZIP** in Finder to unzip.
3. **Drag `SYE - Save Your Eyes.app`** to your **Applications** folder.
4. **Open SYE** from Applications (Launchpad or Finder).

That’s it — no Privacy & Security workaround needed.
