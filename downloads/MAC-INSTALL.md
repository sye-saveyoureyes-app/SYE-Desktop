# Installing SYE on Mac

SYE Desktop is **signed and notarized** by Apple.

## Install

1. **Download** [SYE-mac-1.0.0.zip](/downloads/SYE-mac-1.0.0.zip) (~97 MB).
2. **Unzip** the download in Finder.
3. **Drag `SYE - Save Your Eyes`** to your **Applications** folder.
4. **Open SYE** from Applications.

No Privacy & Security workaround needed.
