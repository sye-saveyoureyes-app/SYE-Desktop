### Install (DMG)

1. Download the DMG
2. Open it → drag **SYE - Save Your Eyes** to **Applications**
3. Open from Applications
4. SYE lives in your menu bar (top-right), not the Dock

Build output: `sye-desktop/out/make/` via `npm run make:release:mac`
